QRVerse Documentation

QRVerse is a professional, client-side QR code generator with a modern SaaS design. Everything runs in your browser — no data is sent to any server. Generate beautiful, scannable QR codes for text, URLs, WiFi, contacts, events, and much more.

💡 Why QRVerse?

Unlike basic generators, QRVerse offers real-time previews, complete visual customization (colors, shapes, gradients, logos), downloadable vector formats, built-in scan verification, and local history — all in a polished, responsive interface.

🚀 Quick Start

  1. Open the generator — Click Generate QR Code on the landing page, or go directly to /#generator.
  2. Pick a type — Choose Text, URL, WiFi, Email, Phone, WhatsApp, SMS, Maps, Contact, Event, or Custom from the left sidebar.
  3. Fill in the fields — The live preview updates instantly as you type. No button press needed.
  4. Customize design — Adjust size, colors, dot style, eye shape, gradients, error correction, and optional logo.
  5. Download / Share — Export as PNG, SVG, JPEG, PDF, copy to clipboard, print, or share via the native share sheet.
  6. Verify it scans — Use the Test Scan button to validate your QR with your webcam or by uploading an image.

🧭 Interface Guide

The dashboard has three main areas:

  • Left sidebar — Switch between the 11 QR types. Your current type is highlighted. On mobile, open it with the hamburger button.
  • Center panel — Dynamic input form matching the selected type. Fields are validated live.
  • Right preview card — Shows a live, animated QR preview plus stats (status, resolution, version, creation time, file types, data length).

Below the preview you'll find all action buttons: PNG, SVG, JPEG, PDF, Copy, Print, Share, New, Clear.

📦 QR Code Types

QRVerse supports 11 different QR code types. Here's everything you need to know about each one.

📝 Text

Encodes a plain string of text. When scanned, the reader will display the raw text content.

// Encoded payload (plain text)
Hello, world! This is a QRVerse QR code.
FieldRequiredDescription
Text Content✔Any text up to ~2,953 bytes (version 40, low EC).

Tip: For longer text, increase the error correction level's partner — larger data yields denser QR grids. Keep the text under ~500 characters for best scannability.

🔗 URL

Encodes a web address. Scanning opens the link in the phone's browser.

// Encoded payload
https://example.com
FieldRequiredDescription
Website URL✔Must include http:// or https://. Validated with the URL constructor.
Remember: QR codes encode exactly what you type. Always include https:// so scanners treat it as a link — otherwise many phone cameras will open it as a text search.

📶 WiFi

Encodes WiFi credentials. Scanning prompts the device to join the network automatically.

// Encoded payload (WiFi config format)
WIFI:T:WPA;S:MyNetworkName;P:SuperSecret123;H:false;;
FieldRequiredDescription
Network Name (SSID)✔The exact WiFi network name.
Password–Network password (empty for open networks).
Encryption–WPA/WPA2, WEP, or No Password.
Hidden Network–Toggle if the SSID is not broadcast.
Security note: Anyone who scans this QR can connect to your network. Only share WiFi codes with trusted people.

✉️ Email

Encodes a mailto: link with optional subject and body. Scanning opens the email app with the fields pre-filled.

// Encoded payload
mailto:someone@example.com?subject=Hello&body=This%20is%20prefilled
FieldRequiredDescription
Recipient Email✔Validated with the standard email regex.
Subject–Pre-filled subject line.
Message–Pre-filled body text.

📞 Phone

Encodes a tel: URI. Scanning offers to call the number.

// Encoded payload
tel:+1234567890
FieldRequiredDescription
Phone Number✔Include country code (e.g., +1). Min 7 digits.

Format: QRVerse strips spaces, dashes, and parentheses, keeping only + and digits.

💬 WhatsApp

Encodes a wa.me link. Scanning opens a WhatsApp chat with that number, optionally with a pre-filled message.

// Encoded payload
https://wa.me/1234567890?text=Hi%20there!
FieldRequiredDescription
Phone Number✔With country code, no spaces. Min 10 digits.
Pre-filled Message–Default text inserted in the chat box.

📱 SMS

Encodes an SMSTO: payload. Scanning opens the messaging app with the number and optional message.

// Encoded payload
SMSTO:+1234567890:Hey, meeting moved to 3pm.

📍 Google Maps

Encodes a Google Maps search query. Scanning opens Maps to that location.

// Encoded payload
https://maps.google.com/?q=Empire+State+Building

You can enter an address, place name, or raw coordinates like 40.7484,-73.9857.

👤 Contact (vCard)

Encodes a full vCard 3.0 file. Scanning prompts the phone to save a contact.

BEGIN:VCARD
VERSION:3.0
FN:John Doe
N:Doe;John;;;
TEL;TYPE=CELL:+1234567890
EMAIL:john@example.com
ORG:Acme Inc.
TITLE:Software Engineer
URL:https://example.com
ADR:;;123 Main St;City;;12345;USA
NOTE:Loves QR codes
END:VCARD
FieldRequiredDescription
Full Name✔Used for both FN and parsed into N.
Phone–Stored as TEL;TYPE=CELL.
Email–Stored as EMAIL.
Organization–Stored as ORG.
Job Title–Stored as TITLE.
Website–Stored as URL.
Address–Stored as ADR.
Notes–Stored as NOTE.

📅 Event

Encodes an iCalendar VEVENT. Scanning prompts the phone to add the event to its calendar.

BEGIN:VEVENT
SUMMARY:Team Meeting
DESCRIPTION:Discuss Q3 roadmap
LOCATION:Conference Room 1
DTSTART:20260806T143000Z
DTEND:20260806T153000Z
END:VEVENT
FieldRequiredDescription
Event Title✔Stored as SUMMARY.
Description–Stored as DESCRIPTION.
Location–Stored as LOCATION.
Start Date✔Local date-time; converted to UTC (ISO 8601).
End Date–Optional; must be after start.
Most Powerful

⚙️ Custom Data

The Custom Data type is the most flexible option. It encodes exactly what you type, with zero formatting or validation. This is how you create advanced QR codes beyond the built-in templates.

How it works

Whatever string you enter becomes the raw payload. The scanner interprets the content based on standardized prefixes. Here's the complete reference:

📋 Standard payload formats

WiFi (if you need more control)
WIFI:T:WPA;S:MyNetwork;P:MyPassword;H:false;;

// Parameters:
// T  = encryption type   (WPA, WEP, nopass)
// S  = SSID / network name
// P  = password
// H  = hidden            (true/false)
// Escape special chars   (\, ;, ,, :, ") with backslash: S:My\;Network
Contact (if you need more vCard fields)
BEGIN:VCARD
VERSION:3.0
FN:Jane Smith
N:Smith;Jane;;;
TEL;TYPE=CELL:+15551234567
TEL;TYPE=WORK:+15559876543
EMAIL;TYPE=WORK:jane@company.com
ORG:MegaCorp
TITLE:CTO
URL:https://company.com
ADR;TYPE=WORK:;;100 Office Pkwy;Springfield;IL;62701;US
PHOTO;ENCODING=b;TYPE=JPEG:...base64...
REV:2026-01-01T00:00:00Z
END:VCARD

// All vCard 3.0 properties are supported by phone address books.
Calendar event (ICS)
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//QRVerse//EN
BEGIN:VEVENT
SUMMARY:Conference
DESCRIPTION:Annual tech conference
LOCATION:Convention Center
DTSTART:20260901T090000Z
DTEND:20260903T170000Z
END:VEVENT
END:VCALENDAR
Cryptocurrency addresses
bitcoin:1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa?amount=0.05&label=Donation
ethereum:0x742d35Cc6634C0532925a3b844Bc454e4438f44e?value=1.5e18
App store / market links
https://apps.apple.com/app/idxxxxxxxx
https://play.google.com/store/apps/details?id=com.example.app
Social media profiles
https://www.instagram.com/username
https://www.tiktok.com/@username
https://www.linkedin.com/in/username
Email with CC/BCC (advanced mailto)
mailto:primary@example.com?cc=cc@example.com&bcc=bcc@example.com&subject=Hello&body=World
Phone call + SMS hybrid
tel:+1234567890
sms:+1234567890?body=Text%20me%20back
Plain text / notes
This is a secret message. Scanners will show it as plain text.
Character limits: QR codes hold a maximum of 2,953 bytes at error correction level L (version 40). Practical limit for reliable scanning is ~700–1,000 characters. Non-ASCII text (emoji, accented characters) uses more bytes. Keep it short.
Pro tip: Use Custom Data when you need to encode a format QRVerse doesn't have a dedicated template for — geolocation (geo:lat,lng), Bitcoin, app links, event details with more fields, or anything else. The payload is passed through 100% untouched.

🎨 Customization

Every design option in the Design panel updates the preview instantly. Here's what each control does:

ControlOptionsDescription
Size128 – 1024 pxOutput pixel dimensions. Larger = crisper when printed/zoomed.
Margin0 – 20Quiet zone padding around the QR (modules). Minimum 4 recommended.
ForegroundColor pickerColor of the data modules (dots).
BackgroundColor pickerBackground color. Use Transparent for logos on colored surfaces.
Dot StyleRounded / Square / CircleShape of the data modules. Circle is softest; Square scans most reliably.
GradientLinear / Radial, 3 colors, directionPick linear or radial, choose direction (linear), and set start / middle / end colors. Optionally apply the gradient to the finder eyes. Gorgeous on colored posters.
Eye ShapeSquare / Rounded / Dot / Extra-roundedStyle of the three finder patterns (corners).
Eye ColorColor pickerOverrides the eye (finder) color separately from dots.

Scannability rule of thumb: High-contrast (dark dots on light background) + square dots + error correction Q/H = the most reliable scans. Use fancy colors & rounded dots for marketing material, but always Test Scan before printing.

🖼️ Logo Upload

  • Accepted formats: PNG, JPG, SVG.
  • The logo is automatically centered with a quiet zone, keeping the finder squares clear.
  • Logo size maps to imageSize = value / 100 (e.g., 20% → 0.2 × QR width).
  • Adds a margin between the logo and QR modules so the code stays scannable.
  • Always use error correction H with a logo — it replaces data capacity with redundancy, so the code still decodes.

🔍 Scan Verification

QRVerse includes a built-in Test Scan tool — no phone needed. Two methods:

  1. Webcam: Opens your camera and decodes QR codes in real time (via html5-qrcode).
  2. Upload image: Upload a screenshot or photo of a QR code and it will be decoded.

The result shows ✔ Scan Successful with the decoded content, or ❌ Invalid QR with a helpful hint.

🕘 History & Favorites

  • Every generated QR is saved automatically to LocalStorage (qrverse_history), capped at 50 items.
  • Each entry shows a rendered thumbnail, title, type, and date.
  • Reuse — restores the type and (where possible) all form values, regenerating instantly.
  • Favorite — toggles the star. Favorites are preserved across sessions.
  • Delete — removes a single item.
  • The search box filters history by title, payload, or type as you type.

🧑💻 REST API Reference

QRVerse ships with a small Express backend exposing the following endpoints:

GET /api/qr/health

curl https://your-app.vercel.app/api/qr/health

// Response
{
  "status": "ok",
  "service": "qrverse-api",
  "timestamp": "2026-08-06T11:07:29.274Z"
}

POST /api/qr/generate

Server-side QR generation (PNG data URL) using the qrcode package.

curl -X POST https://your-app.vercel.app/api/qr/generate \
  -H "Content-Type: application/json" \
  -d '{"data":"https://example.com","options":{"size":300,"errorCorrectionLevel":"H"}}'

// Response
{
  "success": true,
  "dataUrl": "data:image/png;base64,iVBORw0KGgo...",
  "metadata": {
    "size": 300,
    "type": "url",
    "dataLength": 19,
    "timestamp": "2026-08-06T11:07:45.409Z"
  }
}
Request BodyTypeDescription
datastring (required)Payload to encode.
options.sizenumberOutput size in px (default 300).
options.errorCorrectionLevelstringL | M | Q | H (default M).
options.marginnumberQuiet zone (default 4).

💾 Browser Storage

QRVerse stores one key in your browser LocalStorage:

qrverse_history  →  Array of up to 50 history items

Each item is shaped like:

{
  "id": 1234567890,          // timestamp
  "type": "url",             // text|url|wifi|email|phone|whatsapp|sms|maps|vcard|event|custom
  "data": "https://example.com",
  "title": "example.com",
  "date": "2026-08-06T11:07:45.409Z",
  "favorite": false,
  "options": { /* full styling config snapshot */ }
}
Privacy: Everything is stored locally on your device. Clearing your browser data will erase your history. Nothing is ever uploaded to a server.

🔌 QrVerse CDN Scanner

QRVerse ships a self-contained, 100% client-side QR scanning library that anyone can add to an existing project with a single <script> tag. Given an image containing a QR code, it decodes the payload locally in the browser — no backend, no API key, no extra dependencies.

Why use the CDN build?

Everything runs on the visitor's device. The bundle combines the jsQR decoder with a tiny wrapper, so images never leave the browser. Perfect for plugins, widgets, web apps, and tools where you want to read QR codes from uploaded files or webcam frames.

⚙️ Installation

Add one script tag. Choose the minified build for production.

Minified (recommended, ~130 KB)
<script src="https://cdn.jsdelivr.net/gh/v4t3rnomfr/qr-verse@master/cdn/qrverse.min.js"></script>
Readable (development)
<script src="https://cdn.jsdelivr.net/gh/v4t3rnomfr/qr-verse@master/cdn/qrverse.js"></script>
Pin a version in production. Use @1.0.0 (or your app's release tag) instead of @master so your page is unaffected by future releases:

https://cdn.jsdelivr.net/gh/v4t3rnomfr/qr-verse@1.0.0/cdn/qrverse.min.js

After loading, the library exposes a global QrVerse object.

🧑‍💻 API Reference

QrVerse.scan(input, options?) → Promise<Result>

Scans any supported image source and returns the decoded data. Input can be:

  • File / Blob — from an <input type="file">
  • string — a data:image/... URL or an https:// image URL
  • HTMLImageElement — an <img> already on the page
  • HTMLCanvasElement — a canvas with the image drawn on it
OptionDefaultDescription
maxDimension800Downscale images larger than this (px, longest side) for speed.
inversionAttempts'attemptBoth''attemptBoth', 'dontInvert', or true.

Resolved value

{
  "success": true,
  "data": "https://example.com",   // decoded text
  "binaryData": [ ... ],           // decoded bytes (may be null)
  "version": 3,                    // QR version, or null
  "location": { ... },             // corner points, or null
  "alignmentPattern": { ... }      // or null
}

Rejects with a QrVerseError (check err.code) on bad input, or NOT_FOUND when no QR code is detected.

QrVerse.scanImageData(rgba, width, height, options?)

Scan raw RGBA pixels (Uint8ClampedArray) directly — ideal for webcam or video frames.

Convenience methods

  • QrVerse.scanFile(file, options?)
  • QrVerse.scanUrl(url, options?)

🧪 Examples

Scan a file from an input

<input type="file" id="picker" accept="image/*">
<script src="https://cdn.jsdelivr.net/gh/v4t3rnomfr/qr-verse@master/cdn/qrverse.min.js"></script>
<script>
  document.getElementById('picker').addEventListener('change', async (e) => {
    const file = e.target.files[0];
    if (!file) return;
    try {
      const res = await QrVerse.scan(file);
      console.log('Scanned:', res.data);
    } catch (err) {
      console.error('No QR found:', err.message);
    }
  });
</script>

Scan by image URL

const res = await QrVerse.scan('https://example.com/my-qr.png');
console.log(res.data);

Scan a webcam frame (raw pixels)

const ctx = canvas.getContext('2d');
const { data, width, height } = ctx.getImageData(0, 0, canvas.width, canvas.height);
const res = await QrVerse.scanImageData(data, width, height);

❓ FAQ

Do QR codes expire?

No. Once printed or shared, a QR code works forever (unless it links to a resource that disappears).

What's the maximum amount of data I can encode?

Up to 2,953 bytes at version 40 / EC level L. For reliable phone scanning, keep it under ~700 characters, especially with a logo.

Why won't my QR scan?

Common causes: low contrast, insufficient quiet zone (margin), logo too large, distorted/stretched image, or blurry print. Use EC level H, avoid gradients with light dark colors, and always Test Scan.

Is my data sent to a server?

No. All QR generation happens locally in your browser via qr-code-styling. The API endpoint exists for server-side generation via HTTP if you need it.

Can I use QRVerse offline?

Once the page and CDN libraries are cached, the dashboard works fine without connection — generation is fully client-side.

What are error correction levels?

QR codes include redundant data so they survive damage. L=7%, M=15%, Q=25%, H=30% redundancy. Pick H for logos or printed stickers that might get scratched.
